# Hammers.sk
Hammers is a script for Skript that lets you break large areas of blocks in a single swing, with full control over the shape and size of the break area.

## Requirements
- [Skript](https://modrinth.com/plugin/skript) - For running the script.

## Download
You can find the downloads for each version with their release notes in the [releases page](https://github.com/KM1MK2MK358/Hammers/releases).
You can also download it from SkUnity here:[Hammers.sk](https://forums.skunity.com/resources/hammers-sk.1898/)
